# 에셋 키트

산출물은 run의 `assets/`다. 프롬프트는 references/prompts.md, 파일 처리와 마크업은 references/media-pipeline.md, 원장 형식은 references/media-receipts.md에 있다. 스크립트는 `scripts/`에 있다(경로는 run guide의 플러그인 경로 아래 `skills/asset-kit/scripts/`).

## 원칙

1. **고객 자산이 먼저다.** PRD와 디자인 입력에 있는 로고, 사진, 폰트는 그대로 쓴다. 생성은 빈자리만 채운다(Higgsfield `asset-system.md`의 우선 규칙과 같다).
2. **생성 이미지는 이 회사의 실물이 아니다.** 실제 시설, 제품, 직원, 고객, 매장, 시공 사례처럼 보이게 쓰지 않는다. 생성 이미지가 맡는 것은 재료, 공정 클로즈업, 분위기, 익명의 사용 장면, 배경 플레이트다. alt와 캡션도 실물이라고 말하지 않는다. 후기 인물 사진은 만들지 않는다.
3. **이미지 안에 글자를 넣지 않는다.** 글자, 로고, 워터마크, UI는 생성하지 않는다. 글자는 HTML이나 로컬 합성(OG 이미지)으로 넣는다.
4. **스타일 블록은 하나다.** 모든 프롬프트 끝에 같은 블록을 원문 그대로 붙인다.
5. **결과를 모르는 작업은 다시 제출하지 않는다.** 원장에 먼저 기록하고 제출한다.

## 예산 (run 전체, 모든 helper 합계)

PRD가 수를 정하면 PRD를 따른다. 아니면 이미지 12장과 히어로 영상 1개다.

| 슬롯 | 기본 수 | 쓰임 |
| --- | --- | --- |
| hero-still | 1 | 히어로 정지 화면. 영상의 원본, 모바일과 움직임 줄이기 화면, OG 바탕 |
| plate | 3 | 전폭 섹션 이미지와 배경 플레이트 |
| content | 4 | split, mosaic, 카드 이미지 |
| logo-mark | 1 | 고객 로고가 없을 때만. 있으면 content로 돌린다 |
| og | 1 | hero-still 크롭으로 충분하면 예비로 돌린다 |
| reserve | 2 | 재생성, 히어로 후보 2안 |
| hero-video | 영상 1 | hero-still에서 image-to-video |

- 결과물을 만드는 Higgsfield 작업은 모두 센다. 생성, 편집, 배경 제거, 업스케일, 리프레임이 같다. 여러 장을 받으면 받은 장수만큼 센다. `unknown`도 센다.
- 영상은 1개뿐이라 다시 만들지 않는다. 색이 어긋나면 ffmpeg로 보정한다.
- 레퍼런스 보드 이미지는 기본으로 만들지 않는다. PRD가 허용할 때만 12장에서 뺀다.
- 아이콘, 파비콘, OG 글자, 로고 SVG는 로컬에서 만들므로 예산에 들어가지 않는다.
- 브리프 §7에 슬롯별 수량을 적고, 남는 수는 reserve로 둔다.

## 작업 순서

0. **원장 확인.** `assets/media-receipts.json`이 있으면 먼저 읽는다. 이미 제출된 슬롯은 건너뛴다.
1. **슬롯 목록.** 브리프 §6·§7에서 슬롯마다 asset_id, 섹션, 역할, 비율, 데스크톱·모바일 크롭과 초점, 텍스트가 놓일 빈 영역을 정한다.
2. **프롬프트.** `prompts/style-block.txt`와 `prompts/<asset_id>.txt`를 쓴다(references/prompts.md).
3. **제출.** 원장에 `submitting`으로 기록한 다음 제출한다. 서로 의존하지 않는 이미지는 한꺼번에 제출한다. 영상은 hero-still을 확정한 뒤에 제출한다.
4. **대기.** 기다리는 도구로 한 번에 받는다. 모델 턴으로 반복 조회하지 않는다. 기다리는 동안 아이콘과 로고 작업을 한다.
5. **내려받기와 기록.** `src/<asset_id>.<ext>`로 저장하고 sha256, 크기를 원장에 적는다.
6. **일관성 검사 1회.** 아래 절차를 따른다.
7. **로컬 제작.** 아이콘 SVG, 로고 마크 SVG, 파비콘 세트, OG 이미지, 크롭과 파생본, 루프 영상(references/media-pipeline.md).
8. **마무리.** `scripts/receipts_check.py assets`의 `problems`가 비어야 한다. PM에게 슬롯 표(파일, 용도, 크기), job ID, 예산 사용량, 생략한 슬롯과 이유를 돌려준다.

run guide가 Higgsfield를 브로커 경유(media-request)로 지정하면 3–4단계 대신 슬롯별 생성 인자(프롬프트 파일, 모델, 비율, 수)를 PM에게 돌려준다. PM이 요청을 보내고, 결과가 오면 원장을 채운다.

## 일관성 검사 (1회)

`scripts/contact_sheet.sh contact-sheet.jpg src icons logo`로 한 장을 만들고 한 번 읽는다. 장마다 따로 보지 않는다. 결과는 다음 표로 남긴다.

| asset_id | 판정 | 이유 | 조치 |
| --- | --- | --- | --- |
| plate-b | 재생성 | 그레이드가 차갑다(팔레트 밖 청록) | reserve 1 사용, 색 이름을 더 강하게 |

**재생성은 세 경우뿐이다.** 그레이드나 팔레트가 키트와 어긋날 때, 결함(손가락, 글자, 워터마크, 왜곡, 다른 나라 간판)이 있을 때, 피사체가 슬롯 목적과 다를 때다. 재생성은 슬롯당 1회이고 reserve에서 뺀다. 그 밖의 문제는 크롭, 색 보정, 다른 슬롯과 바꾸기로 해결한다. 두 번째 검사는 하지 않는다.

## 이미지 방향

- 피사체는 브리프 §0 "업종의 재료와 말"에서 고른다. 그 업종에만 있는 사물, 재료, 동작이다.
- 사람은 한국 환경에 맞게, 손·작업·중간 거리로 쓴다. 카메라를 보고 웃는 정장 인물은 쓰지 않는다.
- 클리셰 목록과 금지어는 references/prompts.md §6, 한국 기업 사이트 기본값은 homepage-studio `references/design-brief-template.md`에 있다.
- 키트 전체가 같은 빛, 렌즈, 그레이드로 보여야 한다. 한 장만 다르면 그 장이 싸 보인다.

## 아이콘

- 직접 그린 SVG다. 24px 격자, 선 굵기 하나(1.5 또는 2), `stroke="currentColor"`. 6–12개만 만든다.
- Higgsfield 아이콘 시트 생성은 쓰지 않는다. 예산이 들고, 잘라 쓰면 품질이 떨어지고, 래스터라서 색을 바꿀 수 없다. 아이콘 폰트나 CDN 아이콘 라이브러리도 쓰지 않는다.
- 아이콘은 정보를 돕는 곳에만 쓴다. "핵심 가치" 아이콘 카드 3장은 기본값 목록에 있는 패턴이다.

## 로고 (고객 로고가 없을 때)

- 마크만 1장 생성하고 단색 SVG로 옮긴다. 워드마크는 브리프의 폰트로 조판한다. 기준은 Higgsfield brandkit `logo.md`를 본다.
- 브리프 '가정'과 `app/README.md`에 "로고 시안"이라고 적는다.
- 고객 로고는 다시 그리거나 추적하지 않는다. 받은 파일을 그대로 쓴다.

## OG 이미지와 파비콘

- OG는 1200×630 JPG, 300KB 이하다. hero-still을 크롭하고, 카피덱 §7의 문구와 브랜드명을 로컬에서 합성한다. 생성 모델에 글자를 맡기지 않는다.
- 파비콘 세트는 로고 마크 SVG에서 `scripts/favicons.sh`로 만든다. `<head>` 태그는 seo-basics를 따른다.

## 웹 반영

- designer가 `assets/web/`에 파생본을 만들고, developer가 이름을 바꾸지 않고 `app/`으로 복사한다. 결과 URL을 직접 참조하지 않는다.
- 이미지는 AVIF와 WebP의 `<picture>`로 넣는다. 모든 `<img>`에 `width`·`height`를 넣는다. 첫 화면 LCP 이미지만 eager와 `fetchpriority="high"`이고, 나머지는 lazy다.
- 영상은 WebM과 MP4를 함께 넣는다. 768px 이상이고 움직임 줄이기 설정이 없을 때만 재생하며, 일시정지 버튼을 둔다. 마크업은 references/media-pipeline.md '웹 반영'에 있다.
- 용량 상한: LCP 이미지 200KB, 다른 이미지 150KB, 영상 파일당 4MB 목표·6MB 상한, OG 300KB.

## 하지 않는 것

- 웹에서 이미지 내려받기, 스톡 사진, 다른 회사 사진.
- 결과를 모르는 작업 재제출, 예산 초과, 원장에 없는 생성.
- 생성 이미지를 실물 사진처럼 쓰기.
- 일관성 검사와 재생성 반복.
